#review_guidelines:

  - Follow SOLID principles.
  - Check Java code against PMD best practices.
  - Ensure no hard-coded passwords or API keys.
  - Follow Clean Code principles: small methods, meaningful names.
  - Avoid empty catch blocks. Must log or rethrow.
  - Every method must include at least one logger statement.
  - Ensure all Spring Boot REST endpoints have proper authentication/authorization.
  - Controller classes should delegate to services, not contain business logic.
  - Check that @Transactional is only applied at the service layer.
  - Every controller and service must include structured logging.
  - Every controller should communicate through service. 
  - Every method should be well documented.
  - Ensure no Direct Use of Entities in APIs.
  - Ensure DTOs Must Use Java Records.
  - Ensure each class name must be at least 6 characters long
